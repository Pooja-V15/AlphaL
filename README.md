# 🚀 Nexora

## AI-Powered Career Guidance & Skill Development Platform

> Developed by **Team Nexora**

👩‍💻 **Pooja V** • **Harshitha N** • **Chaitanya** • **Bhoomika**

Nexora is an AI-powered career guidance platform that helps students and aspiring professionals discover suitable career paths, identify skill gaps, and generate personalized learning roadmaps through intelligent career analysis and AI-driven insights.

Built during a **one-week development sprint**, Nexora combines career assessments, AI-powered recommendations, skill analysis, and structured career planning into a single user-friendly platform.

---

# 📖 Overview

Choosing the right career path can be overwhelming for students and professionals alike. Many existing career guidance solutions provide generic recommendations without personalized insights into skills, growth opportunities, and long-term career planning.

Nexora addresses this challenge by providing:

- Personalized career recommendations
- Skill gap analysis
- AI-powered career insights
- Learning and growth roadmaps
- Career development reports
- Future career exploration

The platform empowers users to make informed career decisions based on their interests, strengths, and aspirations.

---

# 💡 Problem Statement

Students often struggle to:

- Identify suitable career paths
- Understand their strengths and weaknesses
- Discover industry-required skills
- Plan their learning journey
- Make informed career decisions

Traditional career guidance methods often lack personalization and actionable insights.

Nexora solves this problem by combining AI-powered recommendations, career analytics, and roadmap generation into one intelligent platform.

# 🚀 Getting Started

## Clone Repository

```bash
git clone https://github.com/Pooja-V15/nexora.git
cd nexora
```

## Install Dependencies

```bash
npm install
```

## Configure Environment Variables

Create a `.env` file:

```env
VITE_NVIDIA_API_KEY=YOUR_API_KEY
```

## Run Development Server

```bash
npm run dev
```

## Build Production Version

```bash
npm run build
```

## Preview Production Build

```bash
npm run preview
```
